# WWE All Stars Recomp 1.0.0

**You need your own copy of the game: a disc image of WWE All Stars (Xbox 360,
USA/Europe) and its Title Update 2, both dumped from your own console. DLC is optional
and also comes from your own console. This download contains no game files, no update
and no DLC.**

The first public release: WWE All Stars as a native Windows program, statically
recompiled from the Xbox 360 version with ReXGlue. The
[README](https://github.com/shaneomac1337/WWE-AllStars-Recomp#readme) says what works and
answers the common questions.

## What's in it

- **Native renderer** (the default): the game's Direct3D 9 calls drawn with Vulkan, with
  supersampling, 720p/1440p/2160p render resolution, CAS sharpening, anisotropic
  filtering, Low/Medium/High presets and a Colour setting (*Original*, the Xbox 360's gamma
  curve as in Xenia, or *Natural*, sRGB). The emulated renderer stays as **Emulated**.
- **Shaders and pipelines built before you play**, during setup.
- **PC SETTINGS in the game:** F4, both sticks, or the row in the game's OPTIONS menu.
- **Enhanced vibration:** every hit has its own pulse, plus finishers, slams, reversals and
  critical health. *Original* keeps the console's behaviour.
- **Online Player Match (experimental)** through the game's own Xbox LIVE menus, against
  the project's game server, with a relay so nobody has to open ports. Off by default.
- **Title Update 2.** The port is built on the game's last update, because the DLC
  wrestlers need it: on the disc version the game switches DLC loading off.
- **DLC** from the launcher's DLC page or during setup: package files, a folder, or a zip,
  7z or rar, several packs at once. Every pack is checked block by block. Million Dollar
  Pack (Pack 1) shows its five wrestlers: Million Dollar Man, Honky Tonk Man, Dusty Rhodes,
  Ted DiBiase Jr and Cody Rhodes.
- **The launcher** sets up the game from your disc image and update, repairs a damaged
  install, opens the newest log, makes shortcuts and checks for new releases.
- **Alt+Enter** switches between window and fullscreen; F12 saves a screenshot.

## Install

1. Extract the zip to a normal folder (not Program Files) and run
   `WWEAllStarsLauncher.exe`.
2. Choose your disc image, then Title Update 2, and optionally DLC.
3. Wait for setup to copy, verify and prepare everything, then choose Play.

Windows SmartScreen may warn about the unsigned launcher the first time: choose "More
info", then "Run anyway".

Where Title Update 2 is on your console drive or USB stick: the file
`tu00000005_00000000` in `Content\0000000000000000\54510866\000B0000`, or a file whose
name starts with `TU_` in the console's `Cache` folder. The launcher also takes a folder
with it inside (a whole USB `Content` folder works) or a zip, 7z or rar.

## Known limits

- The in-game store button does nothing; add DLC from the launcher.
- A save made with a DLC wrestler loads without that pack, and the game asks you to
  pick another wrestler.
- Online play pairs only players on the same release.
- Tested on Windows 11 with an RX 7900 XT, and on a Steam Deck. Other GPUs, Windows 10
  and Linux haven't been tried; a bug report with the log helps.
