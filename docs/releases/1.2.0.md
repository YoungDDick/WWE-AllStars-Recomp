# WWE All Stars Recomp 1.2.0

**You need your own copy of the game: a disc image of WWE All Stars (Xbox 360,
USA/Europe) and its Title Update 2, both dumped from your own console. This download
contains no game files, no update and no DLC.**

## What's new

- **120 fps matches** (GRAPHICS tab, experimental, off by default). Offline matches run
  at 120 fps on a 120 Hz or faster display, or with variable refresh. Menus and
  entrances keep their rates, and online matches stay at 60. Some moves can still look
  wrong at 120, such as a wrestler briefly out of place on a running throw. It needs a
  strong GPU: lower the render resolution if frames stutter.
- **Online lobby list** ([#2](https://github.com/shaneomac1337/WWE-AllStars-Recomp/issues/2)).
  The server kept a lobby listed after its host had left, so most of the list was
  lobbies nobody could join. They now go away. This is a server fix, so it already
  works on 1.1.0 too.
- **Friends with a copied game folder see each other online.** A game folder copied to
  another PC took its online ID along, so both PCs played as the same player and never
  saw each other's lobbies. Each PC now makes its own ID. After the update every install
  gets a new online ID once; nothing else changes.

## Update

Extract the zip over your existing folder, or let the launcher's update check take you
to this page. Your settings, saves and game files stay where they are.

## Known limits

- Online play pairs only players on the same release: update together with your
  friends. 1.1.0 and 1.2.0 don't see each other's lobbies.
- Ranked Match doesn't work yet; Player Match does.
- The in-game store button does nothing; add DLC from the launcher.
- Tested on Windows 11 with an RX 7900 XT, and on a Steam Deck (SteamOS through Proton).
  Other GPUs, Windows 10 and desktop Linux haven't been tried; a bug report with the log
  helps.
