# ADR-0010: DLC: required in v1.0, from player-dumped STFS

Status: accepted (2026-10-02)

## Decision

The launcher installs and verifies STFS packages the player has dumped, and the runtime mounts them as content. Nothing is bundled.

## Consequences

This needs the XContent enumeration and mount paths in the runtime, plus the `XeKeysConsolePrivateKeySign` path Xenia trips over.
