# ADR-0008: Online: stub in v1, investigate later

Status: superseded by ADR-0021 (2026-10-05). v1.0 still ships stubbed; online play comes after v1.0.

## Context

Xbox Live and Quazal servers are gone.

## Decision

XNet/XOnline report no connection, so the game shows its own offline message. The Quazal protocol is documented for an investigation after v1.0.
